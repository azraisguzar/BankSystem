# Bank System

This project is a **Bank Management System** application developed using Java and Object-Oriented Programming (OOP) principles.

## 📌 Features
- **Account Management:** Creating customer accounts, managing details, and checking balances.
- **Banking Operations:** Deposit, withdrawal, and money transfer between accounts.
- **Transaction History:** Tracking and logging financial transactions.

## 🛠️ Technologies Used
- **Language:** Java
- **IDE:** Eclipse IDE
- **Version Control:** Git & GitHub
